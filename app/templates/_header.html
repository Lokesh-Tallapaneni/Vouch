{# Site chrome, included by every page via base.html. Reads one optional context variable so this partial degrades cleanly on any page that hasn't wired the account layer into its view yet: - `current_account`: an `Account | None` (app.models.account), e.g. from `app.api.dependencies.CurrentAccount`. Jinja treats an undefined name as falsy, so a page that never passes it just renders signed-out -- nothing breaks. Page-specific navigation links (Task 19): Network is always visible -- it needs no account, same as every other read page. Sign-in/sign-up show only when signed out; the profile edit link only when signed in, since it is the app's one write surface and always resolves to the caller's own id. Sign-out posts to the already-built `/api/v1/auth/logout` (app/api/v1/ auth.py) via htmx rather than a full-page
: that endpoint returns 204 with no body, so a plain form POST would leave the browser showing a blank page. `hx-on::after-request` sends the browser home once the cookie is cleared -- htmx's inline-handler shorthand, no extra JS file needed for one line. The request itself still needs the CSRF header CSRFMiddleware demands of every POST (added after this partial was first written, in the same task that added the profile write) -- see static/js/csrf.js, loaded once in base.html, which attaches it to every htmx request site-wide rather than this button reaching for it one-off. #}
