{# Site chrome, included by every page via base.html. Reads one optional context variable so this partial degrades cleanly on any page that hasn't wired the account layer into its view yet: - `current_account`: an `Account | None` (app.models.account), e.g. from `app.api.dependencies.CurrentAccount`. Jinja treats an undefined name as falsy, so a page that never passes it just renders signed-out -- nothing breaks. Deliberately carries no page-specific navigation links (profile, login): this task owns the design system, not the page routes, and a guessed path that turns out wrong is worse than no link. Whoever wires app/web/pages.py should add those inside site-header__nav alongside the account indicator. Sign-out posts to the already-built `/api/v1/auth/logout` (app/api/v1/ auth.py) via htmx rather than a full-page
: that endpoint returns 204 with no body, so a plain form POST would leave the browser showing a blank page. `hx-on::after-request` sends the browser home once the cookie is cleared -- htmx's inline-handler shorthand, no extra JS file needed for one line. #}
